# 赞云民宿静态宣传页

这是湖南隆回「赞云民宿」的单页静态 HTML 宣传落地页，适合 GitHub Pages、二维码访问、微信分享和手机浏览。

## 文件

- `index.html`：页面结构与图片内容
- `styles.css`：响应式样式
- `script.js`：图片灯箱、按钮提示和轻微滚动动画
- 本地图片：统一存放在 `images/` 文件夹，使用英文规范文件名

## 本地预览

在当前目录启动任意静态服务器即可预览，例如：

```powershell
py -m http.server 8000
```

然后访问：

```text
http://localhost:8000/
```
